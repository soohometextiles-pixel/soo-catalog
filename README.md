## إيه ده؟
ده كتالوج **سو براند** الرسمي: موقع ثابت (HTML) بيعرض أطقم المفارش والملايات بصورها ومقاساتها وأسعارها، والطلب بيتم مباشرة على **واتساب**.

## مميزات الخدمة
- طلب سهل وسريع على واتساب
- توصيل لحد باب البيت في 3 لـ 5 أيام
- معاينة قبل الدفع
- الدفع عند الاستلام، أو فودافون كاش، أو WePay، أو InstaPay

## للي بيدير الموقع
- **كل الأسعار والعروض والجمعة البيضاء وأرقام الواتساب** في ملف واحد: `assets/js/soo-config.js`
- الشرح الكامل خطوة بخطوة: [`docs/دليل-التحكم.md`](docs/دليل-التحكم.md)
- الموقع بيشتغل على GitHub Pages، وأي تعديل بيظهر بعد الرفع بدقيقة تقريباً.
