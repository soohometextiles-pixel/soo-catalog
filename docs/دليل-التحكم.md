# دليل التحكم في موقع سو براند (بدون ما تحتاج حد)

> القاعدة الذهبية: **أي سعر أو عرض أو جمعة أو رقم** بتعدّله من ملف واحد بس:
> `assets/js/soo-config.js`
> أي تعديل فيه بيتطبّق لوحده على كل الصفحات والسلة ورسالة الواتساب.

## 0) إزاي أعدّل أي ملف من GitHub (من الموبايل أو الكمبيوتر)
1. افتح ريبو `soo-catalog` على GitHub.
2. ادخل على الملف (مثلًا `assets` ← `js` ← `soo-config.js`).
3. دوس أيقونة القلم ✏️ (Edit).
4. عدّل، وانزل دوس **Commit changes** (الأخضر).
5. استنى دقيقة أو اتنين وحدّث الموقع.
- GitHub بيحتفظ بكل نسخة قديمة: لو غلطت، من **History** ترجّع الملف.
- **احترس:** الفواصل والأقواس مهمة. كل سطر طقم بيخلص بفاصلة `,` ما عدا آخر سطر في القايمة. لو الصفحة بقت فاضية بعد تعديل، يبقى فيه فاصلة أو قوس ناقص: رجّع آخر نسخة من History.

---

## 1) أغيّر السعر الأصلي لطقم
في `soo-config.js` ← قسم `sets`، غيّر الرقم اللي بعد `"p":`
```
S04: {"t": "...", ..., "p": 1490, "g": "S"},
```
(السعر الأصلي بيظهر مشطوب لما يبقى فيه عرض.)

## 2) أعمل عرض على طقم (عرض عادي)
قسم `offers`، ضيف سطر:
```
S04: { price: 1299, end: '2026-12-01T23:59:00+02:00' },
```
- `price` = سعر العرض (لازم يبقى **أقل** من السعر الأصلي وإلا العرض بيتتجاهل).
- `end` = آخر وقت للعرض. شكله: `سنة-شهر-يوم T ساعة:دقيقة:ثانية +02:00`.
  - في الصيف (توقيت مصر الصيفي) اكتب `+03:00` بدل `+02:00`.
- `start` (اختياري) = وقت بداية العرض لو عايز تجدوله مقدمًا:
  ```
  S04: { price: 1299, start: '2026-12-05T00:00:00+02:00', end: '2026-12-08T23:59:00+02:00' },
  ```
- من غير `end` = العرض مفتوح من غير تاريخ انتهاء (زي الملايات B).
- **لإنهاء عرض:** امسح السطر بتاعه (أو عدّل `end` لوقت فات).
- لما `end` يعدّي: السعر بيرجع للأصلي والطقم بيتشال من صفحة العروض **لوحده**، والعدّاد التنازلي شغال لوحده.
- صفحة العروض بتتبني لوحدها من السطور دي: مفيش حاجة تعدّلها فيها.

## 3) أجهّز عرض الجمعة البيضاء مسبقًا (من غير ما تحتاجني)
في قسم `friday` ضيف سطر **بتاريخ الجمعة**، وجواه كل طقم وسعره في الجمعة دي:
```
friday: {
  '2026-11-20': { S04: 1299, S05: 1399, F01: 799 },
  '2026-11-27': { S01: 1499, F02: 899 },
  '2026-12-04': { B01: 449, B02: 449 }
},
```
- **التاريخ لازم يكون يوم جمعة فعلًا** (سنة-شهر-يوم). الجمعات الجاية: 2026-11-20 / 11-27 / 12-04 / 12-11.
- تقدر تكتب كذا جمعة مقدمًا زي المثال، وكل واحدة بتشتغل لوحدها.
- العروض بتشتغل من **12 بالليل لحد آخر اليوم** وبعدها بتختفي لوحدها، والسعر بيرجع للأصلي.
- قبل الجمعة: صفحة الجمعة بتعرض عدّاد "الجمعة الجاية". يوم الجمعة بيظهر شريط وزرار الجمعة البيضاء على كل الصفحات.
- لو أطقم الجمعة سعرها أقل من عرض عادي شغال: بيتاخد **الأقل**.
- لو جمعة من غير سطر: صفحتها بتفضل "بنجهّز العروض".

### باقة الجمعة (باقة واحدة بسعر ثابت)
قسم `fridayBundles`:
```
fridayBundles: {
  '2026-11-20': { price: 2799, was: 3497, fixed: ['S01', 'F03'], pick: 'B' }
},
```
- `price` = سعر الباقة | `was` = السعر اللي بيظهر مشطوب (اكتب الإجمالي الحقيقي للأطقم من غير عرض، ما تكتبش رقم من عندك).
- `fixed` = أكواد الأطقم الثابتة في الباقة.
- `pick` = المجموعة اللي العميل يختار منها طقم واحد (`B` = الملايات، `S` = الفخامة، `F` = الفلات).
- باقة واحدة لكل جمعة. من غير سطر = مفيش باقة.

## 4) الدفع المقدم والباقات والهدية
- `prepay`: خصم الدفع المقدم لكل مجموعة. `cash` = فودافون/وي باي | `insta` = إنستا باي. الخصم مرة واحدة على الأوردر كله (الأعلى بين المجموعات، مش بيتجمع).
- `bundles`: باقات التوفير بعدد الأطقم، مثال `B: { 3: 1449, 4: 1899 }`.
- `giftMin` و `giftGroup`: الهدية (مثلًا 4 أطقم أو أكتر من S).
- `wa`: أرقام الواتساب اللي بتتوزع عليها الطلبات. `pay`: أرقام الدفع (بتظهر فقط في شاشة الدفع، مش في الصفحة).
- `base`: رابط الموقع (بتغيّره مرة واحدة لو نقلت لدومين).

> لو غيّرت أرقام الواتساب: غيّرها كمان في الفوتر داخل ملفات html (الفوتر فيه 3 أرقام ثابتة). لو عايز أعمل ده بسكريبت قولّي.

---

## 5) أضيف طقم جديد (مثال: ملاية B12)
الخطوات بالترتيب. استخدم أقرب طقم في نفس القسم كنموذج (للملايات: `sheets/b11.html`).

**أ) الصور**
- ارفع الصور في `assets/img/products/` بالأسماء: `b12_1.jpg` و `b12_2.jpg` و `b12_3.jpg` (مقاس 960×1200 تقريبًا، 4:5).
- صورة المعاينة (للسوشيال) في `assets/img/og/` باسم `og-b12.jpg` مقاس 1200×630.

**ب) الإعدادات** (`soo-config.js`)
- في `sets` ضيف:
  ```
  B12: {"t": "ملاية سرير اسم جديد - 4 قطع", "m": "اللون", "i": "assets/img/products/b12_1.jpg", "p": 750, "g": "B"},
  ```
  (`g`: `S` فخامة | `F` فلات | `B` ملايات. وخلي الفاصلة على السطر اللي قبله.)
- في `offers` ضيف لو عايز عرض: `B12: { price: 499 },`

**ج) صفحة الطقم**
1. افتح `sheets/b11.html` ← انسخ كل محتواه.
2. اعمل ملف جديد `sheets/b12.html` والصق.
3. بدّل (Find & Replace): `b11` ← `b12`، و `B11` ← `B12`، واسم الطقم القديم ← الاسم الجديد، واللون القديم ← الجديد.
4. راجع: أسماء الصور، `canonical` و `og:url` و `og:image` (فوق في الملف)، ورسالة الواتساب `data-msg`.

**د) ظهوره في الأقسام**
- `sheets/index.html` و `offers/index.html`: انسخ بلوك `<article class="card pc" id="b11" ...>` لحد `</article>` والصقه بعده وبدّل b11/B11 بالجديد (نفس الاستبدال). وفي `sheets/index.html` ضيف `<a href="../sheets/b12.html">B12</a>` في سطر `chips`، وعدّل العدد "11 طقم".
- الصفحة الرئيسية وصفحات الأقسام فيها عدّاد "11 أطقم" على الكارت: عدّله يدويًا.

**هـ) اختبره** بعد الرفع: افتح الصفحة، اطلب من السلة، وشوف رسالة الواتساب.

> دي أكتر خطوة فيها شغل يدوي. لو عايز: ابعتلي الصور والاسم واللون والسعر وأنا أجهّز لك الملفات الجاهزة بس (الملفات اللي اتعدّلت فقط).

## 6) إزاي أعمل لينك خاص للطقم وأربطه بأي صفحة
- لينك أي طقم: `رابط الموقع + المجلد + الكود.html`
  - مثال: `https://soohometextiles-pixel.github.io/soo-catalog/sheets/b03.html`
- لينك القسم: `.../sheets/` و `.../royal/` و `.../flat/` و `.../offers/` و `.../friday/` و `.../ambassador/` و `.../privacy/`
- تربطه بأي صفحة داخل الموقع بـ:
  ```
  <a href="../sheets/b03.html">اسم الطقم</a>
  ```
  (من صفحة جوه فولدر استخدم `../` قبل المسار. من الرئيسية من غير `../`.)
- لينك السفير: `الرابط?ref=اسم` (بيتعمل من صفحة سوّق واكسب).

## 7) رسالة الواتساب
- **رسالة طقم واحد** (زرار "اطلب الطقم ده"): مكتوبة جوه صفحة الطقم في `data-msg="..."` على وسم `<article class="card ...">`. عدّل النص ما بين العلامتين (الأسطر الجديدة بتتحفظ).
- **رسالة السلة (طلب كذا طقم)**: بتتبني لوحدها من محتوى السلة (الأكواد والأسعار والخصومات والدفع)، وشكلها في `assets/js/soo.js` داخل دالة `buildMsg` (عدّل جملة البداية بس لو عايز).
- **الرسالة العامة** (زرار واتساب العائم): السطر `var GEN='...'` في آخر كل صفحة.

## 8) الرفع بعد التعديل
- ارفع الملفات المتعدّلة بس: افتح الملف على GitHub ← عدّل ← Commit، أو **Add file ← Upload files** لو عدّلت أكتر من ملف.
- أي فولدر جديد: **Add file ← Create new file** واكتب اسمه مع الشرطة (مثال `privacy/index.html`).
- الملفات القديمة اللي اتنقلت امسحها: افتح الملف ← أيقونة الـ ⋯ ← Delete file.

## 9) هيكل المشروع
```
index.html                         الرئيسية
royal/  flat/  sheets/             كل فولدر فيه index.html (صفحة القسم) + صفحات الأطقم
offers/  friday/  ambassador/  privacy/
assets/css/soo.css                 التنسيق
assets/js/soo.js                   المحرك (متلمسوش غير للضرورة)
assets/js/soo-config.js            ← الملف اللي بتعدّل فيه
assets/img/products | og | brand | pay
docs/                              الشروحات
```
